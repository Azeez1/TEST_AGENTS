# Python coding assessment prep

**Window:** Thursday, September 24 through Sunday, September 27, 2026. The assessment is expected next week; adjust the pace when its date is confirmed.

## Current focus: translate logic into Python

The current bottleneck is syntax recall, not breaking down a problem. Start each session with short, unaided drills on function definitions, `if`/`return`, loops, indexing, and building a result. Then apply those pieces to one problem. Keep autocomplete and AI completion off during the drill; use the tutor for feedback after an attempt.

Start with [the first syntax lesson](lessons/0003-for-loops.html). Earlier problem prompts remain below for later practice.

Keep [Coding from first principles](CODING-FIRST-PRINCIPLES.md) nearby: it contains the coding map and the remembering cheat code we developed together.

## How to use this section

Work through one problem with a tutor before moving on. For each attempt:

1. Restate the inputs, output, assumptions, and edge cases.
2. Describe a simple approach and identify its repeated work.
3. Choose a data structure or change in reasoning that removes that work.
4. Write the smallest correct Python implementation.
5. Trace examples, test edge cases, and explain time and space costs.
6. Close the notes and teach the idea back in plain English. On the next day, recall the key idea from a blank page before reviewing anything.

The lesson files hold prompts and your eventual notes. They are not answer keys.
