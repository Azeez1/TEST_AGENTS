Tell Python to visit each character

The basic fact: a string is a sequence of characters. A for loop takes one character at a time from that sequence and gives it a temporary name.

word = "cat"
for letter in word:
    print(letter)

This prints c, then a, then t. Each time through the loop, letter refers to the current character. The colon starts the loop body; the indented line is repeated.

If you only need the characters, this is enough. Later, when you need their positions, you can use indices and range(). See the official Python tutorial.
