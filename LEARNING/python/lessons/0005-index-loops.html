Loop over positions

The basic fact: if a string has 4 characters, its positions are 0, 1, 2, and 3. The position 4 is past the end.

len(s) gives the number of characters. range(len(s)) supplies each valid position, stopping before the length. The loop variable is a number; s[i] uses that number to read the character.

s = "code"
for i in range(len(s)):
    print(i, s[i])

This visits 0/c, 1/o, 2/d, then 3/e. See the official Python tutorial on range().
