Read a character by its position

The basic fact: characters in a Python string have positions. The first position is 0, then 1, then 2. Put the position in square brackets to read that character.

s = "dog"
print(s[0])  # d
print(s[1])  # o
print(s[2])  # g

The position is called an index. s[1] means “read the character at position 1 in s.” Because the first position is 0, position 1 is the second character. See the official Python tutorial.
