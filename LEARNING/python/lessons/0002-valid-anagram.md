# 0002 — Valid Anagram

## Problem

Given two strings, `s` and `t`, decide whether `t` is an anagram of `s`. An anagram contains exactly the same characters the same number of times, though their order may differ. Return `True` if it is an anagram and `False` otherwise.

The strings contain lowercase English letters. They may have different lengths.

## Examples

| `s` | `t` | Result | Why |
| --- | --- | --- | --- |
| `"anagram"` | `"nagaram"` | `True` | The letters match, including repetitions. |
| `"rat"` | `"car"` | `False` | The characters differ. |
| `"aab"` | `"abb"` | `False` | The characters occur a different number of times. |
