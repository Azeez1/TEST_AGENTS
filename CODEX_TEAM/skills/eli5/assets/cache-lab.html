The idea to keep

A cache saves a trip.
A refresh keeps the copy honest.

Reuse when you can. Refresh when it matters.

Connect the picture to the real terms

The shelf is a cache. Finding a usable copy is a cache hit; not finding one is a cache miss. The original lives at the origin. A saved copy that no longer matches the original is stale.

Where this little model stops

This demo has one item, unlimited shelf life, and manual clearing. Real caches may expire entries, check whether an original changed, or receive explicit updates. Nearby is an analogy: caching can avoid computation or disk work as well as network travel. Some data should not be cached.
