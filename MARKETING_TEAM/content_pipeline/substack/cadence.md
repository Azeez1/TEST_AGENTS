# Publishing Cadence

## Weekly Rhythm

| Day | Channel | Content |
|-----|---------|---------|
| **Monday** | LinkedIn | Proof Post — a client result, framework in action, or punchy observation (300-500 words) |
| **Tuesday** | Substack | Weekly essay drops to email list (1,200-1,800 words) |
| **Wednesday** | LinkedIn | FP Breakdown — extract the sharpest frame from Tuesday's essay (different angle, not a repost) |
| **Thursday** | Rest / reply to comments from Wed post | |
| **Friday** | LinkedIn | Framework or lesson — usually standalone, sometimes prefaces next week's essay |
| **Saturday** | Write next week's essay | 2-3 hour deep work block |
| **Sunday** | Review metrics, plan next week's topic | |

## LinkedIn ↔ Substack Integration

**Don't double-post.** Each post on LinkedIn must be a distinct unit, even when derived from an essay.

**Wednesday's LinkedIn post pattern (the essay extract):**
1. Lead with the sharpest single frame from Tuesday's essay (e.g., "The Build-or-Replace Test" from the AI adoption piece)
2. Give 3-6 concrete examples
3. Cap at 500 words
4. Last line: "The full essay with the mechanism behind it is in this week's letter — link in comments"
5. Drop Substack link in first comment

**Why this works:** LinkedIn's algorithm penalizes external links in the post body but not in comments. This gets the post reach AND drives email signups.

## Email Send Time

**Tuesday 6am Central** — hits US East Coast inboxes at 7am (prime time), West Coast at 4am (they see it at wake-up). Pre-schedule Monday night.

## First-Month Plan (Activation Week)

Assumes 10 essays already drafted in `queue/`:

- **Week 0 (setup):** Create Substack publication. Import logo, bio, paid-tier copy. Import 200 contacts as founding subscribers. No send yet.
- **Week 1:** Send first essay Tuesday. Announce on LinkedIn Monday with a "hard launch" post explaining what the publication is. Target: 100 subs by end of week.
- **Week 2-4:** Normal cadence. Use the "2 subs / day" math — 14 subs per LinkedIn post average = 500 subs in 30 days if each post pulls the average.

## When To Pause

If any of these happen, pause the cadence:
- Missed 2 weeks in a row (quality will collapse — stockpile 3 essays before resuming)
- Subscriber growth is negative (< 0 net over 4 weeks — the essay quality or topic fit is wrong, reassess)
- Dux Machina enters active client-acquisition mode and demands all writing focus
