# Substack Pipeline — EZ

Long-form home. Activate when: 10+ banger articles stockpiled + LinkedIn showing consistent 500+ reactions.

## Structure

```
substack/
├── README.md              ← this file
├── brand.md               ← voice, naming, positioning
├── cadence.md             ← publishing rhythm + LinkedIn integration
├── publish_checklist.md   ← pre-publish QA gate
├── template.md            ← starter frontmatter + structure
├── queue/                 ← drafted articles waiting for slot
├── published/             ← archive of published pieces
└── ideas.md               ← backlog of topics pulled from wiki
```

## The Distribution Flywheel

**LinkedIn → Substack → Email list → Dux Machina pipeline**

1. LinkedIn post (300-500 words, piercing hook) teases the full essay
2. Last line of LinkedIn post: "Full breakdown in this week's letter — link in comments"
3. Substack captures email, delivers 1,500-word essay
4. Email list becomes the asset that survives platform shifts and feeds into Dux Machina client acquisition

## Launch Trigger

**Don't activate until:**
- 10+ banger articles drafted and ready in `queue/`
- LinkedIn has posts pulling 500+ reactions consistently
- You have 4+ weeks of runway to publish weekly without missing a beat

**When triggered:**
1. Read `cadence.md` for the week-one plan
2. Read `publish_checklist.md` before every send
3. Use `template.md` as your starter
