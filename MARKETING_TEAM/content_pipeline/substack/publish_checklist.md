# Pre-Publish Checklist

Run this before every send. No exceptions.

## Content QA

- [ ] **Voice test:** read it aloud — does it sound like you, or like an AI wrote it? If AI, rewrite the throat-clearing sentences.
- [ ] **Hook:** first sentence is either an assertion or a question that earns the reader staying. No "In this essay we'll explore..." garbage.
- [ ] **Frame test:** does this piece contain at least one framework the reader can use Monday morning? Or does it just describe a problem? If only the latter, add an actionable filter/test/diagnostic.
- [ ] **Close:** ending is a sharp cut, not a summary. Test: cover the last sentence — is the preceding paragraph still strong?
- [ ] **Wikilinks stripped** for public version — Obsidian wikilinks don't render. Convert to plain emphasis or remove.
- [ ] **No brand name** (Dux Machina / company) inside essay body. Bio only.
- [ ] **No hashtags** anywhere.

## Attribution QA

- [ ] **Primary sources cited** (researchers, papers) where relevant
- [ ] **Popularizers NOT cited** unless they coined a specific term you used
- [ ] **Original frameworks explicitly claimed** in a footnote (prevents "repackager" perception)
- [ ] **Direct quotes attributed** with source

## Technical QA

- [ ] **Subject line tested** for open rate — active verb, specific promise, <60 chars
- [ ] **Preview text written** (first line users see in inbox) — summarizes the frame, not the topic
- [ ] **Images have alt text** for accessibility and email-client rendering
- [ ] **Any external links open in new tab** (don't kill the reading flow)
- [ ] **Mobile preview looks clean** — check in Substack's preview before send
- [ ] **Paywall positioned correctly** if paid tier — before the tactical payoff, not after

## Distribution QA

- [ ] **LinkedIn Wednesday post** drafted and scheduled
- [ ] **Substack link in LinkedIn first comment** ready to paste
- [ ] **Tweet thread optional** if the essay has a standalone frame worth teasing elsewhere

## Post-Send

- [ ] **Tag the essay in Obsidian vault** with `published:YYYY-MM-DD`
- [ ] **Move from `queue/` to `published/`** in this repo
- [ ] **Log metrics 48 hours after send**: open rate, click rate, sub growth, paid conversions
- [ ] **Grab the 3 most-highlighted lines** for future LinkedIn carousel material

---

**If any of the Content QA items fail, do not send.** One bad essay costs more subscribers than three mediocre ones, because unsubscribes compound.
