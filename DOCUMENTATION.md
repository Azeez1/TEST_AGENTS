## 🎯 Documentation Quality Standards

All documentation in TEST_AGENTS follows these standards:

**Structure:**
- Clear headings and hierarchy
- Table of contents for long docs
- Cross-references to related docs
- Examples and code snippets

**Content:**
- Action-oriented (tell users what to do)
- Troubleshooting sections included
- "See also" links to related topics
- Up-to-date with current system

**Maintenance:**
- Updated when system changes
- Deprecated docs moved to archive/
- Version history in CHANGELOG.md
- Regular audits for accuracy

## 📝 Contributing to Documentation

**When to update docs:**
- Adding new agents
- Creating new tools/skills
- Changing workflows
- Fixing bugs that affect usage
- Updating API configurations

**Where to document:**
- New features → Update relevant guide + CHANGELOG.md
- New tools → Update TOOL_REGISTRY.md
- New agents → Update MULTI_AGENT_GUIDE.md + team README
- Configuration changes → Update MEMORY_SYSTEM.md or API_SETUP_GUIDE.md
- Breaking changes → Update CHANGELOG.md + affected docs

**How to update:**
1. Make changes to relevant .md files
2. Update cross-references if needed
3. Test examples and code snippets
4. Commit with descriptive message
5. Update CHANGELOG.md
