# Video Intelligence Workspace

This folder is the repository home for `$video-intelligence` inputs, outputs,
rubrics, and curated examples. The globally installed skill code remains under
`C:\Users\sabaa\.codex\skills\video-intelligence` so Codex can use it from any
workspace.

- `inbox/`: local videos supplied for analysis; gitignored.
- `outputs/analyses/`: timestamped real-video runs; gitignored.
- `outputs/tests/`: generated fixtures and smoke-test runs; gitignored.
- `rubrics/`: reusable custom analysis rubrics; tracked.
- `examples/`: deliberately curated, safe-to-commit examples; tracked.

Do not place API keys, credentials, private client media, or unreviewed outputs
in tracked folders.
